# Backblaze submission — Thikra: A Provenance-Aware Agentic Media Fulfillment Network

A paid external order enters the existing multi-provider Genblaze pipeline. Provider choices, costs, source/generated assets, verification, retries, manifests, and receipts form a persisted evidence graph. Backblaze B2 durably stores production artifacts through `genblaze-s3` and the approved evidence-storage abstraction; short-lived URLs return the accepted package.

The demonstration emphasizes multi-provider generation, bounded agentic retry, durable object storage, lineage, verification, and production-minded asynchronous fulfillment.
