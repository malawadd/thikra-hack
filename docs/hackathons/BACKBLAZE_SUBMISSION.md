# Backblaze submission

## Project

Thikra — Verify-Then-Pay Creative Commerce.

Thikra makes Backblaze B2 the durable accountability layer for autonomous creative procurement. Genblaze writes source, intermediate, final, and manifest artifacts; Thikra records object keys, hashes, lineage, payment references, verification, decisions, and exportable evidence. Browsers receive only short-lived server-generated downloads.

## Demonstration

The Noura Glow scenario compiles a bounded mandate, compares providers, authorizes a simulated/Prava sandbox transaction, runs the existing Genblaze multi-provider path, identifies a controlled delivery defect, retries within budget, requests human approval, and exposes every artifact and audit relationship.
